## 💻 Projeto

A Calculadora de IMC é uma simples calculadora que mede índices de massa corporal, a partir de dados introduzidos pelo próprio usuário. Além disso, indica se está abaixo do peso, peso ideal, sobrepeso, etc.

## 🚀 Tecnologias

Esse projeto foi desenvolvido com as seguintes tecnologias:

- HTML e CSS
- JavaScript
- Git e Github
